# 介绍下函数索引、位图索引、空间索引

::: caution
内容来源网络，仅供学习使用。<br/>
**不要相信文档中的链接、联系方式等！！！**

**函数索引**基于表中一列或多列的函数结果创建的索引。好处就是可以解决用了函数之后索引就失效了的问题。

这个功能在 MySQL 中也支持，只不过在8.0之后，相关原理一样的：

[08.MySQL_MySQL用了函数一定会索引失效吗](../08.MySQL/MySQL用了函数一定会索引失效吗.md)

位图索引使用一系列bit来表示数据记录是否存在。bitmap 索引将每个被索引的列的值作为 KEY，使用每个 bit 表示一行，当这行中包含这个值时，设置为 1，否则设置为 0。

详见：

[52.Oracle_Oracle_支持哪些索引类型](./Oracle_支持哪些索引类型.md#vuefS)

**空间索引，**是专门用于索引地理空间数据，如使用SDO\_GEOMETRY类型的数据。如我们介绍过的 R 树索引和四叉树索引都是空间索引

[52.Oracle_Oracle_支持哪些索引类型](./Oracle_支持哪些索引类型.md#Gz4Ip)
